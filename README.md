# Moviezer Releases

Public update assets for Moviezer desktop and Android. Source code lives in private Moviezer repositories.

## Downloads

Use the file names to choose the right build:

- `Moviezer-Setup-*.exe` - Windows desktop installer.
- `Moviezer-*.exe` - Windows desktop portable app.
- `Moviezer-Android-*.apk` - Android phone, tablet, or TV app.
- `latest.yml` and `*.blockmap` - desktop updater metadata; users normally do not download these manually.

Android users should uninstall any debug/test build before installing the first release APK. After that, future release APKs signed with the same key can update normally.
